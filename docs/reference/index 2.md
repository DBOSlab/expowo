# Package index

## All functions

- [`POWOcodes`](https://dboslab.github.io/expowo/reference/POWOcodes.md)
  : Complete list of vascular plant families and associated URI
  addresses
- [`accGraph()`](https://dboslab.github.io/expowo/reference/accGraph.md)
  : Create graphics of species discoveries accumulation and
  nomenclatural changes
- [`angioData`](https://dboslab.github.io/expowo/reference/angioData.md)
  : List of Angiosperm species
- [`angioGenera`](https://dboslab.github.io/expowo/reference/angioGenera.md)
  : List of Angiosperm genera
- [`botregions`](https://dboslab.github.io/expowo/reference/botregions.md)
  : Countries and associated classification of botanical divisions
- [`get_year_pubs()`](https://dboslab.github.io/expowo/reference/get_year_pubs.md)
  : Secondary function to transform data generated with powoSpecies
- [`megaGen()`](https://dboslab.github.io/expowo/reference/megaGen.md) :
  Extract megadiverse genera of any plant family
- [`powoFam()`](https://dboslab.github.io/expowo/reference/powoFam.md) :
  Extract species number of any plant family
- [`powoGenera()`](https://dboslab.github.io/expowo/reference/powoGenera.md)
  : Extract list of genera for any plant family
- [`powoMap()`](https://dboslab.github.io/expowo/reference/powoMap.md) :
  Create global maps of species richness
- [`powoSpDist()`](https://dboslab.github.io/expowo/reference/powoSpDist.md)
  : Extract distribution of any plant species
- [`powoSpecies()`](https://dboslab.github.io/expowo/reference/powoSpecies.md)
  : Extract list of species for any plant genus and family
- [`saveCSV()`](https://dboslab.github.io/expowo/reference/saveCSV.md) :
  Fastly save CSV file within a current date folder
- [`topGen()`](https://dboslab.github.io/expowo/reference/topGen.md) :
  Extract the top most species-rich genera of any plant family
