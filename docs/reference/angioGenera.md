# List of Angiosperm genera

Complete list of all genera and associated data of Lecythidaceae,
Aristolochiaceae, Begoniaceae, Martyniaceae, Dipterocarpaceae, and
Fagaceae, as retrieved from POWO database in January 2023 using the
`expowo`'s function `powoGenera`.

## Usage

``` r
data(angioGenera)
```

## Format

`data.frame`
