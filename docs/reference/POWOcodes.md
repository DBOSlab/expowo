# Complete list of vascular plant families and associated URI addresses

Complete list of the vascular plants (APG IV-based families of flowering
plants, gymnosperms, ferns and lycophytes) and associated URI addresses
as retrieved with the function `get_pow` of the package
[taxize](https://docs.ropensci.org/taxize/index.html).

## Usage

``` r
data(POWOcodes)
```

## Format

`data.frame`
