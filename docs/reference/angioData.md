# List of Angiosperm species

Complete list of all non-hybrid species and associated data of
Lecythidaceae, Aristolochiaceae, Martyniaceae, Cabombaceae, and
Begoniaceae, as retrieved from POWO database in November 2022 using the
`expowo`'s function `powoSpecies`.

## Usage

``` r
data(angioData)
```

## Format

`data.frame`
